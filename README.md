This is an upload to a Google Apps Script for a evaluation system for a school district with about 150 staff members. The idea was to create a evaluation system that had a component for observation for teachers and could take a rubric
and show it as an observed level and give the supervisor a chance to rate the overall section. This uses components of URL variables and internet HTML 5 variable storage. 
Spreadsheets were used to as a way to store the information like a database and to help with calculations as with teachers there are 3 different calculations, and then there are evauation systems for ed techs, technicians, etc.  You can see the different rubrics that are the application reads in the main branch with the name of the job position.

Each nested branch is a Google Apps Script project with the main section being the file Code.gs which then directs the users to the needed .html file within that same branch.
